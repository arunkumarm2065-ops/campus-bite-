CampusBite — new features setup
================================

FILES IN THIS PACKAGE
  wallet.js            REPLACE your old wallet.js (bug fix + admin-only "Reverse" for added money)
  firestore.rules      REPLACE and publish (adds rewards + report e-mail collections)
  cb-functions.js      NEW  (calls Cloud Functions)
  rewards.js           NEW  (milestone rewards: admin tab + student button)
  monthly-report.js    NEW  (admin tab for monthly e-mail reports)
  chatbot.js           NEW  (💬 chatbot)
  functions/           NEW  (Cloud Functions: monthly e-mail, reward claim, optional AI chat)

STEP 1 — index.html: add 4 lines at the very bottom, after <script src="order-tools.js"></script>
  <script src="cb-functions.js"></script>
  <script src="rewards.js"></script>
  <script src="monthly-report.js"></script>
  <script src="chatbot.js"></script>

STEP 2 — Publish firestore.rules (Firebase console > Firestore > Rules).
  Wallet fix, wallet reversal and the chatbot (built-in answers) work after steps 1-2. No server needed.

STEP 3 — Cloud Functions (needed for: monthly e-mail, reward claiming, optional AI chatbot)
  Cloud Functions need the Firebase "Blaze" (pay-as-you-go) plan. A small canteen stays inside the free quota,
  but a billing account must be attached.
  1. npm install -g firebase-tools   then   firebase login
  2. In your project folder:  firebase init functions   (choose existing project campus-bite-demo, JavaScript)
     Then copy functions/index.js and functions/package.json over the generated ones.
  3. cd functions && npm install && cd ..
  4. Secrets for sending e-mail (use a Gmail account with 2-step verification, then create an "App password"):
        firebase functions:secrets:set SMTP_USER        (the Gmail address)
        firebase functions:secrets:set SMTP_PASS        (the 16-letter app password)
     Only if you want the AI chatbot:
        firebase functions:secrets:set ANTHROPIC_API_KEY
     (the function file lists all three; if you skip the AI key, create it with any placeholder value
      or delete the askCampusBite block and the ANTHROPIC_API_KEY line before deploying)
  5. firebase deploy --only functions

HOW EACH FEATURE WORKS
 1) Wallet (admin)
    - Bug: the student list was redrawn on every live update and every 3 seconds, which wiped the amount box.
      It now redraws only when data really changes and keeps what you typed.
    - Ledger rows for "Top-up" and "Added by admin" now have a red Reverse button (admin only).
      It takes the same amount back, adds a "Reversed by admin" line, and can only be done once per top-up.
      If the student already spent part of it, the reversal is refused (balance never goes negative).
      Students cannot create reversal lines: the Firestore rules only allow topup/payment from students.
    - Tip: if only the admin should add money, set ALLOW_STUDENT_TOPUP = false in wallet.js
      and demoTopUpAllowed() to return false in firestore.rules.

 2) Monthly sales report e-mail
    Admin > 📧 Monthly Report: type each canteen owner's REAL e-mail (owner logins such as 001@campusbite.app
    are not real mailboxes), tick "Send automatically", Save. On the 1st of every month at 8:00 AM India time
    the function e-mails last month's sales (completed orders only). "Send now" tests it immediately.

 3) Milestone rewards (admin controlled)
    Admin > 🏆 Rewards: create goals, e.g. "10 orders in a month -> ₹25" or "Spend ₹500 -> ₹50".
    Pause, edit or delete any time. Students see progress in the 🏆 button and press Claim; the bonus goes to the
    wallet as a "Reward bonus" ledger line. The server re-checks progress and blocks double claims, so it cannot be cheated.
    Only COMPLETED orders count. Monthly goals reset on the 1st (India time).

 4) Chatbot
    💬 button bottom-right. Answers from live data: menu, prices, stock, timings, your order, wallet, rewards.
    For free-form AI answers: deploy the function, then set AI_ENABLED = true at the top of chatbot.js.
    The API key lives only in Firebase secrets, never in the browser. Each user is limited to 60 AI messages a day.

NOTE ON THE MASCOTS: they use position:fixed too; the chat button sits bottom-right at z-index 9990, below the mascots (9998).
